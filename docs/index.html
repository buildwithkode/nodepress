🔌 1. System Integration (How Everything is Connected)

EcommPress seamlessly links your storefront, payment gateways, and courier logistics into one unified architecture:

Phase A: Cart, Promo & Universal Shipping Calculation

When the customer checks out on your frontend, NodePress calculates: Total = Subtotal - Discount + ShippingFee. If subtotal ≥ ₹1,500 (or coupon is FREE_SHIPPING), delivery fee is ₹0; otherwise flat ₹99 is added.

Phase B: Razorpay UPI Intent & Cryptographic Webhooks

NodePress converts the amount to paise (₹2,499.50 = 249950 paise) and returns an authenticated payload. The frontend opens the native Razorpay modal (GPay, PhonePe, Paytm, QR). Upon payment, Razorpay notifies the backend via HMAC-SHA256 webhook, and NodePress atomically deducts the variant SKU stock and transitions the order to PAID.

Phase C: Courier AWB Tracking & Automated Tax Invoices

The store owner books pickup with their courier aggregator (Shiprocket, Delhivery, BlueDart, FedEx) and enters the tracking number on the /commerce Orders table. The order transitions to SHIPPED with a live tracking link, and an itemized HTML/PDF tax invoice is generated with 1 click.

🎛️ 2. Dedicated Commerce Hub (/commerce)

The admin panel provides a complete table-based management suite with 7 dedicated sections:

🏠 Home / Overview

Revenue KPI cards, total paid checkouts, Average Order Value (AOV), and low-stock inventory alerts.

📦 Orders Table

Searchable table with Order #, Customer, Total, Payment & Fulfillment badges, Courier AWB, and 1-click invoice print.

🏷️ Products Table

Searchable catalog with Thumbnails, SKUs, Categories, Prices, Stock levels (color-coded), and Variant matrix pills.

👤 Customers Table

Aggregated buyer directory with Name, Email, Total Orders, Lifetime Value (LTV total spend), and Location.

🎟️ Discounts Table

Promo codes table with Percentage, Fixed, and Free Shipping types, Minimum spend limits, and Create Coupon modal.

🚚 Shipping & Markets

Flat Rate Delivery rules, Free Shipping Thresholds, and supported courier carrier links.

🚀 3. Quick Installation

Install the package into your NodePress project backend:

npm install @nodepress-pro/ecommerce

Register the plugin in backend/src/plugin/plugins.config.ts:

import { EcommerceProManifest, EcommerceProModule } from '@nodepress-pro/ecommerce';

export const ENABLED_PLUGINS = [
  { manifest: WordCountManifest, module: WordCountModule },
  { manifest: SeoAnalyzerManifest, module: SeoAnalyzerModule },
  { manifest: EcommerceProManifest, module: EcommerceProModule }, // 👈 Registered
];

🔑 4. License Key Activation (Lemon Squeezy)

Purchases on Lemon Squeezy issue a unique key (e.g. 83AD5792-2E0D-...). When saved in the Admin Settings drawer, NodePress contacts Lemon Squeezy's /v1/licenses/activate endpoint and binds your domain.

⚡ Localhost Evaluation Mode: On localhost and 127.0.0.1, testing is automatically unlocked with zero key required.

🚚 9. Shipping & Courier Fulfillment

Calculate flat rates or free delivery above threshold, and fulfill orders with tracking numbers:

Rate Formula: Final Total = Subtotal - Discount + Shipping Fee

If cart subtotal ≥ ₹1,500, shipping fee is ₹0 (Free Delivery).

Mark order as fulfilled with tracking AWB:

PATCH /api/commerce/orders/:id/fulfill
{
  "carrier": "Shiprocket",
  "trackingNumber": "SR100982348"
}

🧾 10. Automated Tax Invoices

Retrieve itemized, printable HTML/PDF tax invoices with breakdown:

GET /api/commerce/orders/:id/invoice
